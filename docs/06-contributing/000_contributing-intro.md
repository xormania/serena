# Contributing

**If you want to *use* Serena** — connect it to a coding agent, configure languages, work with
projects — [Usage](../02-usage/000_intro) is where to start. Nothing in this section is needed for
that.

This section is for working on Serena itself.

The rules for a contribution — what can go straight to a pull request and what wants an issue
first, how to set up a development environment, which checks have to pass before you commit — are
in [CONTRIBUTING.md](https://github.com/oraios/serena/blob/main/CONTRIBUTING.md) at the repository
root. That file is the authority and this section does not restate it.

What belongs here is the part a single file cannot carry: a guided way into the code.
[Code Reference](code-reference/000_code-reference-intro) is generated from the docstrings in
`src/serena` and is ordered the way you meet the package rather than alphabetically, so it can be
read forwards on a first pass and used as a lookup afterwards.
